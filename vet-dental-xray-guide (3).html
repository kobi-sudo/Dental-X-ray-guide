Dogs & Cats
Canine
Dog dental views
Use bisecting angle for maxillary and rostral mandibular teeth. Parallel technique for caudal mandibular premolars and molars. Full series = 12–16 views.
Maxillary incisors · 101–103 / 201–203
Bisecting angle — one image captures all 6 upper incisors
~60°
  • →Patient sternal; palate parallel to table; foam support under chin
  • →Sensor placed horizontally and palatally behind incisors (size 2)
  • →Foam wedge holds sensor at the correct angle
  • →Beam aimed at ~60° from vertical, over the bridge of the nose
  • →One image typically captures 101–103 and 201–203
  • →Roots look stubby → beam too steep; reduce angle. Roots too long → increase angle
⚠ Aim at the ROOT apex, not at the crown — roots are roughly 2× crown length
Maxillary canine · 104 / 204
Bisecting angle + lateral oblique — aimed mesially to avoid PM3
~60° oblique
  • →Sternal; head tilted toward the side being imaged
  • →Largest sensor palatally alongside canine (size 4 ideal, size 2 minimum)
  • →Foam wedge essential — very limited palatal space
  • →Beam oblique at ~60°, aimed MESIALLY so long root does not overlap PM3
  • →Increase exposure 10–15% — most underexposed view in the series
  • →Periapical lucency at apex = endodontic disease until proven otherwise
⚠ Full root length must be visible on image — apex must show before any extraction
Maxillary 4th PM (carnassial) · 108 / 208
3 roots: mesio-buccal (MB), disto-buccal (DB), palatal (P) — use SLOB to separate
~45° + SLOB
  • →Sternal; head tilted toward side being imaged
  • →Sensor palatally at ~45°; foam wedge to hold
  • →Take standard view first — MB and palatal roots often superimpose
  • →Shift tube HEAD mesially 15–20° and retake (SLOB rule)
  • →Compare both images side-by-side — roots now separated and identifiable
  • →Most common tooth for endodontic disease and retained roots post-extraction
⚠ Always image AFTER extraction — confirm all 3 roots fully removed
Mandibular PM & molars · 305–311 / 405–411
Parallel technique — no angle calculation needed; most accurate
Parallel
  • →Lateral recumbency; targeted side facing DOWN
  • →Sensor placed lingual to teeth, as parallel to roots as possible
  • →Foam wedge holds sensor in position during exposure
  • →Beam perpendicular (90°) to both tooth and sensor — straight down
  • →Usually 2 images per side to cover PM2–M3 in large breeds
  • →Don't substitute bisecting angle here — parallel is far more accurate

Feline
Cat dental views
Size 0 or 1 sensor throughout. Short jaws and flat palate make positioning harder. Expect 10–12 views. FORLs (feline odontoclastic resorptive lesions) are very common — always scrutinise the crown/root junction carefully.
Sternal recumbency → maxillary viewsDorsal recumbency → mandibular viewsSize 0 sensor throughoutAlways image before extracting — FORL type changes technique
Maxillary canine · 104 / 204 — the trickiest feline view
Short palate · size 0 sensor · FORLs extremely common
~45° oblique
  • →Sternal; head tilted toward side being imaged
  • →Size 0 sensor placed as far palatally as possible
  • →Dental putty or finger cot holds sensor — no room to hold manually
  • →~45° oblique, aimed MESIALLY to avoid PM3 (shallower than dog)
  • →FORLs type 1 and 2 common at cervical line — type changes extraction technique
  • →May need 2 attempts — partial root images are NOT acceptable
⚠ Full root tip must be visible before ANY extraction — retake if not
Maxillary PM & molar · 106–109 / 206–209
Shallower than dog — zygomatic arch consideration
~30–40° oblique
  • →Shallower angle (~30–40°) than equivalent dog view — zygomatic arch interferes
  • →Digital sensors partially see through the arch
  • →PM4 (108/208): two-rooted (MB + palatal) — may need SLOB
  • →Molar (109/209): three roots — same approach as dog 4th PM
  • →FORLs most common at PM3–PM4 furcation area
  • →Size 0 sensor throughout — furcation involvement usually means extraction

Core techniques
Positioning techniques explained
Understanding the geometry prevents the most common errors. There are only three techniques — master these and every view becomes straightforward.

Bisecting angle technique

Default for all maxillary teeth and rostral mandibular teeth — any view where the sensor cannot be parallel to the root.

How to do it

  • Visualise the long axis of the tooth (crown tip to root tip)
  • Find the plane of the sensor
  • Mentally bisect the angle between them
  • Aim the beam PERPENDICULAR to that bisecting line
  • NOT perpendicular to the tooth. NOT perpendicular to the sensor.

Quick angle reference

  • Max. incisors: ~60°
  • Max. canine (dog): ~60° oblique
  • Max. canine (cat): ~45° oblique
  • Max. PM (dog): ~45°
  • Max. PM (cat): ~30–40° (zygomatic arch)
  • Mand. incisors/canines: ~20–30°

Parallel technique

Gold standard — sensor parallel to root, beam 90° to both. Only usable for caudal mandibular teeth in dogs.

Where to use

  • Mandibular PM and molars in dogs (305–311 / 405–411)
  • Near-parallel for feline mandibular PM/M

Why it's better

  • No bisecting angle mental arithmetic
  • Accurate root length — zero distortion
  • Less operator-dependent error

Why not used everywhere

  • Palate prevents parallel sensor placement for maxillary teeth
  • Mandibular symphysis blocks rostral mandibular views
  • Cat mandible too narrow for true parallel
  • Only the long dog mandible creates enough lingual space

SLOB rule — separating superimposed roots

Same Lingual · Opposite Buccal
  • Take standard view first — note which roots overlap
  • Shift tube mesially 15–20° — retake
  • Buccal roots move in SAME direction as tube
  • Palatal/lingual root moves in OPPOSITE direction
  • Compare both images to identify each root
  • Don't shift more than 20° — causes elongation

Used for

  • Upper 4th PM dog (108/208) — MB, DB, palatal
  • Upper molar cat (109/209)
  • Any multi-rooted tooth with overlapping roots
Quality control
Common errors & fixes
Most radiograph errors are one of these eight. Recognising them quickly means faster retakes and less anaesthetic time.
Foreshortening
Looks like
Teeth appear shorter — roots stubby
Cause
Beam too steep (overangulated)
Fix
Reduce beam angle — tilt tube away
Tip
Most common with maxillary incisors
Elongation
Looks like
Teeth appear longer — roots stretched
Cause
Beam too shallow (underangulated)
Fix
Increase beam angle — tip more toward teeth
Tip
Common when hesitating over steep nose angles
Cone cut
Looks like
White crescent cutting across image corner
Cause
Beam not centred over sensor
Fix
Centre beam over middle of sensor before exposing
Tip
Touch sensor centre as a guide first
Superimposition
Looks like
Roots overlap — cannot see individual roots
Cause
Not enough oblique angle
Fix
Add lateral oblique; apply SLOB rule
Tip
Compare two images with tube shifted
Motion blur
Looks like
Double edges; margins indistinct
Cause
Patient movement; sensor shift
Fix
Check depth; secure sensor with foam
Tip
Stable foam under sensor not on table
Flipped / mirrored
Looks like
Image mirrored; teeth on wrong side
Cause
Sensor placed back-to-front
Fix
Dotted/pimple side always faces beam
Tip
Label R/L immediately after every image
Root tip cut off
Looks like
Apex not visible; root truncated
Cause
Sensor not far enough apically
Fix
Push sensor apically; use largest sensor
Tip
Always include 3mm beyond apex
Overexposed / dark
Looks like
Image too dark; tooth detail lost
Cause
kVp or exposure time too high
Fix
Reduce exposure 20% or kVp by 5
Tip
Cats need far lower settings — create presets
