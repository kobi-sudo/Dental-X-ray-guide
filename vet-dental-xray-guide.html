Dog dental views
Full-mouth canine series. Use bisecting angle for maxillary and rostral mandibular teeth; parallel technique for caudal mandibular premolars and molars.
Maxillary incisors  ·  101–103 / 201–203
Bisecting angle technique — one image captures all 6
~60°
Position
Sternal; palate parallel to table; foam support under jaw
Sensor
Horizontal, placed palatally behind upper incisors; size 2
Beam
Aimed rostrally at ~60° from vertical over the bridge of the nose
Tips
  • One image usually captures 101–203 in medium dogs
  • Aim at roots not crowns — roots are roughly 2× crown length
  • If roots look stubby: reduce beam angle (overangulated)

Maxillary canine  ·  104 / 204
Bisecting angle + lateral oblique — avoid PM3 superimposition
~60° oblique
Position
Sternal; head tilted toward side being imaged
Sensor
Palatally alongside canine; size 2 or 4 if available; foam wedge essential
Beam
Lateral oblique ~60°, aimed mesially so the long canine root doesn't overlap PM3
Tips
  • Longest root in the mouth — always use the largest sensor you have
  • Most commonly under-exposed view — increase exposure by 10–15%
  • Periapical lucency = endodontic disease until proven otherwise
⚠ Always include 3mm beyond the root apex — essential for periapical assessment and post-extraction confirmation

Maxillary 4th PM — carnassial  ·  108 / 208
Three-rooted tooth — bisecting angle + SLOB for root separation
~45° + SLOB
See Techniques tab for SLOB diagram
Position
Sternal; head tilted toward side being imaged
Sensor
Palatally alongside PM4; angled at ~45°; large sensor preferred
Beam
Bisecting angle ~45°; then apply SLOB (move tube mesially/distally) to separate 3 roots
Tips
  • 3 roots: mesio-buccal (MB), disto-buccal (DB), palatal (P) — standard view often superposes MB + palatal
  • Most common tooth for endodontic disease and retained roots post-extraction
  • Always image post-extraction to confirm complete root removal
Mandibular PM & molars  ·  305–311 / 405–411
Parallel technique — most accurate; long mandible makes this possible
Parallel
Position
Lateral recumbency; targeted side facing downward
Sensor
Placed lingual to teeth, as parallel to tooth roots as possible; foam wedge to maintain
Beam
Perpendicular (90°) to both teeth and sensor — no bisecting angle calculation needed
Tips
  • The long dog mandible makes this the one region where true parallel works reliably
  • Gives the most accurate root length — don't substitute bisecting angle here if you can avoid it
  • Usually 2 images per side to cover PM2–M3 in large breeds
Photo: Niemiec BA. Patient positioning (lateral recumbency). J Feline Med Surg 2014. PMC11044607

Feline
Cat dental views
Use size 0 or 1 sensor throughout. Short jaws and flat palate make positioning more challenging. Expect 10–12 views. FORLs (feline odontoclastic resorptive lesions) are extremely common — always scrutinise the crown/root junction carefully.
Patient positioning overview
Setting up for maxillary vs. mandibular views
Key principle
Maxillary views
Sternal recumbency; hard palate parallel to table; small foam block or bite platform under the chin maintains level head
Mandibular views
Dorsal recumbency; mandible parallel to table; handle ET tube carefully when rolling patient
Key point
The image in the photo (Fig 4, Niemiec 2014) shows exactly these two positions — (a) dorsal for mandibular canines/incisors, (b) lateral for maxillary cheek teeth

Maxillary canine  ·  104 / 204 — the trickiest feline view
Short palate makes sensor placement very limited
~45° oblique
Why hardest
Short feline palate leaves almost no room to angle the sensor; foam putty or small bite block essential
Sensor
Size 0 or 1, placed as far palatally as possible; finger cot over sensor helps with comfort; use dental putty to hold angle
Beam
~45° oblique, aimed mesially — avoids superimposing canine root on PM3
Tips
  • FORLs (type 1 and 2) extremely common at the cervical line
  • May need 2 attempts — partial root images are not acceptable for treatment decisions
  • If root type 2 FORL: root may be replaced by bone — can change extraction plan
⚠ A partial root image without the apex is not diagnostic — retake before any extraction

Core techniques
Positioning techniques explained
Three techniques used in veterinary dentistry. Understanding the geometry prevents the most common errors.

Bisecting angle technique

The default technique for all maxillary teeth and rostral mandibular teeth. Required wherever the sensor cannot be placed parallel to the root.
Niemiec 2014 — PMC11044607

How to do it

  • Visualise the long axis of the tooth (crown-to-root direction)
  • Identify the plane of the sensor lying in the mouth
  • Mentally bisect the angle between them
  • Aim the beam perpendicular to that imaginary bisecting line

Beam too steep (overangulated)

  • Teeth appear shorter — foreshortening
  • Fix: reduce beam angle; pull tube head back

Beam too shallow (underangulated)

  • Teeth appear longer — elongation
  • Fix: increase beam angle; tip tube more toward teeth

Quick reference angles

  • Max. incisors: ~60°
  • Max. canine: ~60° + oblique
  • Max. PM: ~45°
  • Mand. incisors/canines: ~20–30°
  • Cat max. PM/M: ~30–40° (zygomatic arch)

Parallel technique

Gold standard — sensor parallel to tooth root, beam perpendicular to both. Only usable for caudal mandibular teeth.
Niemiec 2014 — PMC11044607

Where to use

  • Mandibular premolars and molars in dogs — long jaw allows true parallel
  • Near-parallel for feline mandibular PM/M

Why it's better

  • No bisecting angle mental calculation required
  • Accurate root length representation
  • Less operator-dependent error

Why not used everywhere

  • No arched palate in dogs/cats means maxillary sensor can't be placed parallel to roots
  • Mandibular symphysis blocks sensor placement for rostral mandibular teeth

SLOB rule — separating superimposed roots

Same Lingual · Opposite Buccal

When the tube is moved mesially:

  • The buccal root moves in the same direction as the tube (mesially)
  • The lingual/palatal root moves in the opposite direction (distally)

Used primarily for:

  • Upper 4th PM in dogs (108/208) — separates MB, DB, and palatal
  • Upper molar in cats (109/209)
  • Any multi-rooted tooth with superimposed roots on standard view

In practice: take a standard view first, note which roots overlap, then shift tube mesially 15–20° and retake. Compare both images side by side to identify each root. Move no more than 20° to avoid excessive elongation.

Common errors & fixes
Most radiograph errors fall into a handful of repeatable patterns. Recognising them quickly means faster retakes and less anaesthetic time.
Foreshortening
Looks like
Teeth appear shorter than real — roots look stubby
Cause
Beam too steep (overangulated) — perpendicular to jaw, not to bisecting line
Fix
Reduce beam angle — tilt tube away / raise head slightly
Tip
Most common with maxillary incisors — if roots disappear into the nasal cavity, you're too steep
Elongation
Looks like
Teeth appear longer than real life — roots stretch
Cause
Beam too shallow (underangulated)
Fix
Increase beam angle — tip tube more steeply toward teeth
Tip
Common when hesitating to use steep angles over the nose
Cone cut
Looks like
White crescent or arc cutting across corner of image
Cause
Beam not centred over sensor; collimator misaligned
Fix
Centre beam over middle of sensor before exposing
Tip
Touch sensor centre with a finger as a guide, then position tube over it
Superimposition
Looks like
Roots overlap; cannot distinguish individual roots
Cause
Not enough oblique angle; roots aligned with beam
Fix
Add lateral oblique; use SLOB for multi-rooted teeth
Tip
Compare two images with tube shifted mesially/distally
Motion blur
Looks like
Double edges; tooth margins indistinct; ghosting
Cause
Patient movement; sensor shift; unsecured tube head
Fix
Check anaesthetic depth; secure sensor with foam; lock tube head
Tip
Place sensor on stable foam, not directly on table surface
Flipped / mirrored
Looks like
Image mirrored; teeth appear on wrong side
Cause
Sensor placed with active face away from beam; software flip
Fix
Dotted/pimple side always faces beam; check software orientation
Tip
Label all images R/L immediately; set software to auto-label
Root tip cut off
Looks like
Apex not visible; root truncated at sensor edge
Cause
Sensor not positioned far enough apically
Fix
Push sensor further apically; use larger sensor for dog canines
Tip
Always include 3mm beyond apex — essential for periapical assessment
Overexposed / dark
Looks like
Image too dark; tooth detail lost; bone structure washed out
Cause
Exposure time or kVp too high; small patient on large-dog settings
Fix
Reduce exposure time by 20% or reduce kVp by 5
Tip
Cats need significantly lower settings — create size-based software presets
